# Capstone Report
 
## ERP-Integrated Manufacturing & Supply Chain Control Tower
 
### Abstract
 
This project develops an ERP-inspired decision-support platform for a high-precision machining company. The framework integrates inventory optimization, supplier performance management, procurement analytics, and production planning into a centralized control tower to improve operational visibility and decision-making.
 
---
 
## Problem Statement
 
Manufacturing organizations often manage inventory, procurement, supplier performance, and production planning through separate systems. This fragmented approach can lead to excess inventory, procurement inefficiencies, production delays, and limited visibility across operations.
 
The purpose of this project is to develop an integrated framework that consolidates these functions into a single decision-support environment.
 
---
 
## Business Environment
 
The organization operates within a precision machining environment that includes:
 
- CNC Turning
- CNC Milling
- Grinding Operations
- Quality Inspection
- Final Dispatch
 
The facility sources raw materials, tooling, consumables, and bought-out components from domestic and international suppliers.
 
---
 
## Methodology
 
The project was executed in four phases:
 
### Phase 1 – Data Collection
 
Collection of:
 
- Material master data
- Supplier master data
- Procurement data
- Inventory data
 
### Phase 2 – Inventory Optimization
 
Application of:
 
- Economic Order Quantity (EOQ)
- Safety Stock Planning
- Reorder Point Calculation
 
### Phase 3 – Procurement & Supplier Analytics
 
Evaluation of:
 
- Supplier performance
- Procurement spend
- Lead times
- Quality metrics
 
### Phase 4 – Production Planning
 
Analysis of:
 
- Machine capacity
- Resource allocation
- Production scheduling requirements
